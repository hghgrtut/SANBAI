# Правила работы в репозитории SANBAITeam

## Git: индексация файлов (обязательно)

После выполнения любой задачи агент **обязан** проиндексировать (`git add`) все новые и изменённые им файлы.

Правила:

- Индексировать **явными путями**, а не через `git add .` / `git add -A`.
- Перед завершением задачи проверить, что ничего не забыто:
  `git ls-files --others --exclude-standard -- '*.kt' '*.xml' '*.kts' '*.toml'`
  и `git status --short -uno`. Каждый новый файл должен иметь статус `A`.
- Коммит **не** создавать без прямой просьбы пользователя. Только индексация.

## Конвенции кода

- UI-строки на русском, лежат в `res/values/strings.xml` соответствующего модуля.
- Названия типов тренировок — `TrainingPieceType` (`data/local`), у каждого есть `uiResId`; строки для них уже
  существуют, переиспользовать их, а не создавать дубли.
- Тексты ресурсов `data/local` доступны в любом модуле через `stringResource(type.uiResId)`.
